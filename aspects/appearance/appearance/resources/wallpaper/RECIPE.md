# Astra · 程序化壁纸配方

四张静态壁纸的设计参数。此文件可直接交给 SVG / ImageMagick 制作者；本次只交付设计与 HTML 中的 CSS 近似缩略图，不生成或安装系统壁纸。

## 共用生成协议

- 画布 `width=2560 height=1600 viewBox="0 0 2560 1600"`，比例16:10，sRGB。建议先以5120×3200栅格化，再Lanczos降至目标尺寸，最后添加噪声。输出不透明8位RGB PNG，保留sRGB色彩标识，不附文字或水印。
- 坐标和线宽均为最终物理px；高分辨率处理时乘2。渐变均 `gradientUnits="userSpaceOnUse"`，`color-interpolation="sRGB"`。混合统一 source-over，后列出的图层在上。SVG路径超出画布部分裁切。
- 唯一源色：bg `#1e2228`、deep `#181b20`、surface `#272c33`、selection `#323843`、blue `#61afef`、cyan `#56b6c2`、border `#5c6370`、brightFg `#d7dae0`、black `#0e1013`。未列出的源色本组不使用。中间像素由这些颜色插值和透明合成得到。
- 所有彩色层只作低浓度罩染，绝不直接以100% blue/cyan铺面。上方0–160px为顶栏安静区，不放尖锐轮廓。主工作区中央x=300–2050、y=160–1300不放高频结构。

### 确定性噪声（四张共用，强度和seed分表）

不要使用未指定seed的ImageMagick `+noise`。推荐在最终8位sRGB图上逐像素生成单通道灰噪声，三个颜色通道加同一个值，避免彩色噪点。

1. 行优先遍历，初值 `state=seed`（32位无符号）。每个像素先更新 `state=(1664525*state+1013904223) mod 2^32`。
2. `u=state/4294967295`；噪声 `n=A*(2*u-1)`，单位为8位码值。
3. R/G/B分别做 `round(clamp(channel+n,0,255))`；A如下表。这是最终栅格阶段，不在每个图层重复添加。平均噪声为0，无颜色漂移。
4. SVG单文件预览可用 `feTurbulence type="fractalNoise" baseFrequency="0.72" numOctaves="1" seed="…" stitchTiles="stitch"`，转单通道后用极低alpha混合；它只是近似，不能声称与上面的LCG噪声像素相同。HTML使用细小透明纹理近似，不承担精确噪声复现。

## 01 · 静湾 / Quiet Bay

构图：右下大面积缓慢弧面，好像一张石墨纸轻轻弯起。顶部和左上保留连续暗面。三条轮廓依次向右下收拢；蓝青只存在于最外层的柔光，不形成发亮霓虹线。

| 顺序 | 几何 | 填充 / 线条 |
|---|---|---|
| 1 | 全画布rect | 线性G1：起(0,0)止(2560,1600)，0% deep、52% bg、100% surface，全不透明 |
| 2 | 椭圆cx=2200 cy=1450 rx=1360 ry=850 | 径向G2：中心blue alpha .09，48% cyan alpha .035，100% cyan alpha 0；不加描边 |
| 3 | `M -180 1540 C 480 1430 790 1580 1390 1180 C 1910 830 2150 740 2760 840 L 2760 1800 L -180 1800 Z` | 线性G3起(700,780)止(2050,1720)：0% selection、46% surface、100% deep；整体opacity .70 |
| 4 | `M 180 1740 C 900 1430 1090 1490 1610 1190 C 2060 930 2390 1070 2740 1080 L 2740 1800 Z` | G4起(1280,1020)止(2560,1680)：0% surface、100% deep；opacity .86 |
| 5 | `M 740 1740 C 1250 1450 1600 1550 1940 1330 C 2290 1110 2530 1290 2770 1250 L 2770 1800 Z` | deep，opacity .95 |
| 6 | 与第3层上缘同路径，仅stroke不闭合 | border alpha .22，宽1.2；路径终点在(2760,840) |
| 7 | 与第4层上缘同路径，仅stroke不闭合 | blue alpha .07，宽1.0 |
| 8 | 全画布边缘暗角 | 径向中心(1280,720)，rx1600 ry1200；0–50% black alpha0，100% black alpha .22 |
| 9 | 全画布 | LCG噪声seed241024，A1.0 |

SVG径向椭圆可用半径1的radialGradient配合 `gradientTransform="translate(2200 1450) scale(1360 850)"`。第3–5层不模糊，光层自身渐变完成过渡。不要给轮廓加投影。

## 04 · 夜纸 / Night Paper

构图：从左上deep到右下bg的近单色纸面。对角面只改变极少亮度。适合作为“几乎没有壁纸”的长期基底。

| 顺序 | 几何 | 参数 |
|---|---|---|
| 1 | 全画布 | G1起(0,0)止(2560,1600)：0% deep、55% bg、100% surface |
| 2 | 多边形 `0,1000 1700,0 2200,0 0,1320` | G2起(0,900)止(1800,0)：0% surface、100% bg；整体opacity .26 |
| 3 | 多边形 `480,1600 2560,370 2560,720 1100,1600` | deep，alpha .20 |
| 4 | 斜线族，k=0…7：起(-500+480k,1600)，止(500+480k,0) | stroke border alpha .035，宽1；超出画布裁掉 |
| 5 | 全画布 | LCG噪声seed241027，A1.6 |

无需模糊。锁屏若用本张，仍由Noctalia增加原生tint/blur；不要把密码文字烧进壁纸。

## 缩放、导出与验收

- 3840×2400或5120×3200版本按相同比例放大所有坐标；噪声始终在最终像素尺寸生成，不放大已有噪点。16:9显示器优先中心裁切，确保曲线主重心仍在右下；需要适配则重新生成，不拉伸。
- 主色必须仍为低饱和深灰；不以自动对比度、HDR、高光锐化或色彩增强处理导出文件。由于原色混合会产生中间值，不能用“每个像素仅允许16色”的索引色模式。
- 以空桌面、白色网页、两侧终端三种场景检查。壁纸不是文字背景的唯一保护层；应用正文保持实底。桌面顶栏范围应没有强色带、山脊或高频噪点。
- HTML里的四张缩略图只用于比较构图；正式图应按本文件路径生成，不从缩略图截图放大。

实施覆盖：用户要求正式图片比本稿更亮、渐变更明显、带柔和蓝/青光晕。`render.py` 保留本稿曲线/圆环/纸面构图与 LCG 种子，将底部终点提到 selection，光晕提升到 .24（夜纸 .13），增加 .09 的宽幅柔光。未使用自动提亮或独立源色。

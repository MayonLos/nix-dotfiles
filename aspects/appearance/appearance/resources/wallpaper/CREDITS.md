# Retained repository wallpapers

The cool-toned rotation uses the existing repository images `wallpaper-002.png`,
`wallpaper-005.png`, `wallpaper-008.png`, `wallpaper-009.png`, and
`wallpaper-011.png`; the default is `wallpaper-005.png`.

Their original provenance was not recorded in this branch; no new attribution
is invented for them. All twelve original `wallpaper-0xx.png` files remain
unchanged. User-provided images belong in `~/Pictures/Wallpapers/local/` and are
not fetched, overwritten, or deleted by this factory.

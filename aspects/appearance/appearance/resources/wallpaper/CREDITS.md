# Repository wallpapers

The rotation uses the 18 original images first added in commit `553d8b1`
(`home/wallpaper/`), restored on 2026-10-29 at the user's request. The default
is `wallpaper-005.png` (2560x1600), which the greeter and lock screen also use.

Their original provenance was not recorded; no attribution is invented for
them. User-provided images belong in `~/Pictures/Wallpapers/local/` and are not
fetched, overwritten, or deleted by this factory.

# System maintenance

Provides system-wide Nix settings, locale/time zone, sudo-rs policy, basic maintenance tools, and `nh` cleanup configuration. `host.flakePath` is an optional host binding input consumed by `nh`; the aspect does not discover a repository path.

Outputs include bounded journald storage, automatic Nix store optimization, configured substituters/keys and experimental features, locale definitions, password-authenticated wheel sudo-rs, maintenance utilities, and `nh` retention (`--keep 5 --keep-since 14d --keep-one`; the last flag keeps one gcroot per direnv project so project devshell sources survive cleanup). `keep-outputs=false` explicitly retains Nix's normal GC reachability policy rather than pinning all outputs of live derivations. The locked NixOS module supplies root trust and the official cache key, so this feature only adds third-party signing keys. Nix local build parallelism is a laptop hardware policy, not a generic maintenance default. Substituters are ordered by the `priority` URL parameter: the USTC, Nanjing and CERNET mirrors at 10, 20 and 30, nix-community at 40, Numtide at 45, and the official cache last at 50, because a lower number is queried first and a path missing from one cache falls through to the next. The three mirrors serve `cache.nixos.org` content and are signed with the same key, so they add no key entries; Tsinghua was measured returning 404 for store paths and is not included. The list replaces NixOS's `mkAfter` cache entry, which carries the default priority 0 and would otherwise outrank every mirror. `download-buffer-size` is raised from the 1 MiB default to 64 MiB for large transfers; that buffer is shared by concurrent downloads rather than allocated per download. Store deduplication stays scheduled rather than adding work to every store insertion. No low-space automatic GC thresholds are added while the audited root filesystem has about 504 GiB available; NH retains its weekly generation policy. This feature does not remove logs or run cleanup itself.

`contract.nix`, `default.nix`, `nix.nix`, `locale.nix`, `tools.nix`, and `nh.nix` are owned private files. Removing the feature withdraws these system declarations after a system activation. Existing logs, generations, user files, and store contents remain until separate cleanup actions are explicitly run.

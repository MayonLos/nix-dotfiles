# System maintenance

Provides system-wide Nix settings, locale/time zone, sudo-rs policy, basic maintenance tools, and `nh` cleanup configuration. `host.flakePath` is an optional host binding input consumed by `nh`; the aspect does not discover a repository path.

Outputs include bounded journald storage, automatic Nix store optimization, configured substituters/keys and experimental features, locale definitions, password-authenticated wheel sudo-rs, maintenance utilities, and `nh` retention (`--keep 5 --keep-since 14d`). `keep-outputs=false` explicitly retains Nix's normal GC reachability policy rather than pinning all outputs of live derivations. The locked NixOS module supplies root trust and the official cache key, so this feature only adds third-party signing keys. Nix local build parallelism is a laptop hardware policy, not a generic maintenance default. The official/community/Noctalia/Numtide caches remain available to the selected packages. Download buffers retain the installed Nix default; store deduplication stays scheduled rather than adding work to every store insertion. No low-space automatic GC thresholds are added while the audited root filesystem has about 504 GiB available; NH retains its weekly generation policy. This feature does not remove logs or run cleanup itself.

`contract.nix`, `default.nix`, `nix.nix`, `locale.nix`, `tools.nix`, and `nh.nix` are owned private files. Removing the feature withdraws these system declarations after a system activation. Existing logs, generations, user files, and store contents remain until separate cleanup actions are explicitly run.

# File manager

Installs File Roller for the selected user and host-wide Thunar, GVfs, thumbnailing, archive and volume plugins. It needs the normal package set; host support is routed through `file-manager-host-support`. `packages.nix` is the single private package factory. No other feature should import its implementation files.

## Finder shell and preference ownership

The Thunar 4.20.9 package carries `resources/finder-shell.patch` and `resources/finder.css`. The shell uses one native toolbar: back, forward, breadcrumb/location, view switcher and search. Ctrl+L edits a path; clicking the empty breadcrumb space does the same. Ctrl+M toggles the traditional menu; F10 opens it temporarily. The patch makes the existing `menu:0` toolbar preference effective, so hiding the menubar does not force an extra menu button. `menu:1` remains available. The native toolbar editor, icon/list/compact views, split view, tabs and statusbar remain available through menus and keyboard shortcuts.

The sidebar separates GTK bookmarks into **Favorites / 收藏**, followed by the original **Places / 位置**, **Devices / 设备** and optional network group. Favorites and Places retain their headings when empty, providing a stable drop target for first/multiple bookmarks and when all native Places entries are hidden. Devices and Network retain upstream empty-group visibility. Existing bookmark names, paths, order, hidden state, rename/remove and bookmark-file monitoring remain native. Dragging a folder before the Places header appends it to Favorites; reordering existing bookmarks still uses their original IDs. Header cell renderers use smaller medium text and the current GTK secondary color. CSS supplies neutral selection with a thin blue left marker, a lighter column header, modest row spacing and low-contrast dividers. File names, path labels and headers use Inter / Noto Sans CJK SC. WhiteSur icons are selected by the appearance feature, not by this feature.

`preferences.nix` runs `resources/seed-preferences.sh` at the Home Manager write boundary. It queries the live Xfconf writer and **only creates missing properties**; it never replaces `thunar.xml`. New profiles receive the toolbar above, hidden menubar, breadcrumb navigation, details view, a 190 px sidebar, and name/date/size columns. Existing values win, including menu visibility, view type, toolbar order, separator position, column choices and unknown properties. An old `last-toolbar-item-order` or `last-toolbar-visible-buttons` prevents seeding the new toolbar key so upstream can migrate it. Consequently an existing profile can retain its former layout until its owner changes it in Thunar; activation does not infer that a saved default was an explicit user choice. It does not seed or rewrite bookmarks. Query failures abort instead of treating all preferences as absent. Activation reuses the supplied session bus or an existing runtime user bus; before login, when neither exists, a private Xfconf-only bus seeds and flushes the same configuration. It does not try to autolaunch a graphical session.

Noctalia/session-support remains the only writer of the shared GTK palette and generated user GTK CSS. The package loads its scoped geometry resource in the Thunar process after that palette (provider priority 801), without writing another user GTK file or restarting a service. Colors use the shared GTK semantic roles, including `accent_color` for the thin blue marker. Other GTK applications are unaffected. The patch applies at build time and its source anchors fail on incompatible upstream changes. This is a native Thunar shell, with a native breadcrumb, search, overflow and menu behavior; it does not implement Finder column browsing or imitate macOS window controls.

## Preserved behavior

All nine managed custom actions retain their commands, IDs, keyboard bindings, English fallback names/descriptions and `zh_CN` translations: terminal, Neovim, herdr, lazygit, wallpaper, copy image, copy path, paste clipboard image and paste link. Lower-frequency herdr/lazygit entries remain in the native `Development` submenu because the locked UCA parser does not translate submenu labels. The wrapper defaults to Chinese only when `LANGUAGE` is unset; it sets `LC_MESSAGES=zh_CN.UTF-8` only if `LC_MESSAGES` and `LC_ALL` are also unset. Explicit locale choices remain effective. Child applications may inherit that locale.

Templates remain missing-only seeds for blank text, Markdown, Python, shell, Lua and Nix files. Existing templates and a user-owned `Templates` symlink are untouched. File Roller archive actions, thunar-volman, GVfs, Tumbler, open-with and directory MIME defaults remain in their existing ownership paths. Clipboard actions support Wayland/X11. Wallpaper uses Noctalia on Mango and feh on Xorg; the Xorg wallpaper daemon can later replace that nonpersistent choice.

The host installs the tailored package once in system packages, D-Bus and systemd, with Xfconf enabled. This matches the locked NixOS `programs.thunar` module, which has no package option. The canonical `org.freedesktop.FileManager1.service` points to the same wrapped Thunar `--gapplication-service`; HM does not install another Thunar or a per-user bus override. Only the wrapper's symlinks to the upstream XFCE/GNOME wallpaper plugin are removed; original store files are untouched.

## Files, removal and verification

Owned implementation: `default.nix`, `host.nix`, `packages.nix`, `preferences.nix`, `thunar-actions.nix`, `thunar-terminal.nix`, `templates.nix`, `resources/finder.css`, `resources/finder-shell.patch`, `resources/seed-preferences.sh`, `resources/check-preferences.sh`, and the registered `checks.nix` hook. Runtime ownership includes the managed UCA XML/helper configuration, one copied image accelerator, host service registration and missing-only seeds. Removing the feature withdraws packages, host services and managed declarations; it leaves seeded preferences, templates, bookmarks and application data. HM can back up a former managed file under the host backup policy.

`file-manager-actions` checks all nine translated actions, executable dependencies, MIME defaults and template preservation. `file-manager-dbus` builds/checks the actual tailored Thunar package, canonical services, locale wrappers and archive TAP. `file-manager-preferences` executes the actual activation on a private D-Bus/Xfconf fixture: fresh defaults, repeated activation, edited/unknown settings old toolbar migration keys, and activation before login followed by a fresh-bus persistence read. Headless screenshots verify the real app separately; evaluation/build evidence does not establish physical mounts, real clipboard interoperability or behavior in the user's running session.

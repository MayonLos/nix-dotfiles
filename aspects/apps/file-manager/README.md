# File manager

Installs File Roller for the selected user and host-wide Thunar support for Thunar, GVfs, and thumbnailing. It needs the normal package set; host support is routed through `file-manager-host-support`.

Outputs include the managed Thunar custom actions, terminal launcher integration, File Roller archive plugin, missing-only `~/Templates` seeds for blank text, Markdown, Python, shell, Lua, and Nix documents, volume management, GVfs, and Tumbler. Custom actions open the current directory in the configured terminal, open files in Neovim, start herdr or lazygit in a directory, set images through the current session command, copy paths or image data on the active Wayland/X11 display, paste clipboard images as new PNG files, and create symlinks from copied file URIs. Existing custom action configuration is represented declaratively by `thunar-actions.nix`.

`packages.nix` is the single package factory for the archive and volume plugins and `thunarWithPlugins`. Host support installs this package once; the selected user finds it through the system profile. Its FileManager1 service uses the canonical `org.freedesktop.FileManager1.service` filename and the wrapped Thunar binary with the upstream `--gapplication-service` argument. Home Manager no longer installs a second Thunar or a per-user FileManager1 override. The shared session-support D-Bus renderer retains standard user service discovery and merges explicit host service directories by bus name.

Thunar and its settings dialog default to Simplified Chinese through their own wrapper when `LANGUAGE` is unset; a user-provided `LANGUAGE` remains in effect, and C locales disable translations. Child applications launched from Thunar may inherit `LANGUAGE`. In a Noctalia session, the shared session-support GTK3 asset template gives Thunar a compact toolbar, menus, path bar, sidebar, and file list in the One Dark palette. Filenames keep the sans-serif family, path/header/status text uses the palette monospace family, and selected rows retain a neutral selection surface with a narrow blue inset marker. Noctalia remains the single writer of the generated GTK CSS.

Owned files are `default.nix`, `host.nix`, `packages.nix`, `thunar-actions.nix`, `thunar-terminal.nix`, `templates.nix`, and `checks.nix`; all Nix files are private except the registered check hook. The feature owns the FileManager1 service in the tailored host package. The activation only creates missing template files, skips a user-owned `Templates` symlink, and leaves existing templates untouched. Noctalia exposes a wallpaper-set command for Mango. The current Xorg wallpaper daemon only exposes next/rotation; its custom action can update the visible image with feh, but the daemon does not persist that choice and can later replace it. Removing the feature withdraws its packages, host services, and managed action declarations; it does not delete seeded templates or application data. An existing HM-managed file may be backed up according to the host backup policy.

The locked NixOS `programs.thunar` module has no package option. Host support registers the tailored package in system packages, D-Bus and systemd, and enables Xfconf explicitly, matching that module’s four registrations. The wrapper removes only its symlinks to the upstream wallpaper plugin: its native menu supports XFCE/GNOME and otherwise does nothing, so the session-aware UCA is the sole wallpaper action. No upstream store files are changed.

The lower-frequency herdr and lazygit custom actions share the native `Development` submenu. All nine custom actions carry English fallback names and descriptions plus `zh_CN` variants. Thunar 4.20.9 selects localized `name` and `description` values using `xml:lang` and the process `LC_MESSAGES` locale; the UCA parser does not localize submenu labels, so that submenu remains `Development`. The Thunar wrapper supplies `zh_CN.UTF-8` only alongside its default Chinese `LANGUAGE`, and only when `LC_MESSAGES` and `LC_ALL` are both unset. Explicit locale choices are preserved. Action IDs, commands, and accelerators are unchanged. The shared GTK writer keeps file-list and sidebar separators at 6 px while slightly reducing toolbar icon scale and column-header vertical padding.

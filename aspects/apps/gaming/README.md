# Gaming

Configures gaming tools for a selected user and routes shared NixOS support through `gaming-host`. The host side owns Steam, Gamescope and GameMode integration; the user side configures MangoHud and Prism Launcher. The user's GameMode group membership is part of this feature.

Outputs include Steam and host gaming support, MangoHud metrics, and Prism Launcher with the selected Java toolchains, FFmpeg, MangoHud, Gamescope, and GameMode support. When the user has an appearance palette, it installs Prism's One Dark theme from the public `desktop/session-support.qt-style.nix` factory plus a Prism-only stylesheet. Main-window top and instance action toolbuttons have transparent default surfaces, with a quiet border on hover and a blue border for pressed, checked, or focused states. Prism settings tabs use a clear blue underline, nested group boxes lose duplicate slabs while keeping checkable indicators visible, disabled editor fields remain readable, and dialog footer buttons use compact spacing. A native Prism cat pack supplies the low-contrast geometric prism in the instance library, and a native icon theme replaces only the top `cat` action while inheriting `pe_colored` for other icons. Select `One Dark` under Settings → Appearance → Theme, `One Dark Prism` under Icon Theme (stored ID `NixDotfilesPrism`), and `Nix Dotfiles Prism` under Cat Pack (stored ID `NixDotfilesPrism`) once. Prism owns these selection settings and account/instance state. GPU-specific GameMode device settings come from host facts in the hardware feature.

Owned files are `default.nix`, `host/`, `mangohud.nix`, `prismlauncher.nix`, `resources/prism/`, and the explicit test hook `checks.nix`; implementation Nix files are private. Removing the feature withdraws package, service, group declarations, theme, icon theme and cat pack files when activated. It preserves Steam libraries, game saves, Prism instances, downloaded mods, launcher accounts, and Prism's selected appearance settings.

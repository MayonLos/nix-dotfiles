# Documents

Installs document applications and chooses handlers for documents. It reads `user.appearance` for the Zathura and Obsidian palette templates.

The locked Obsidian package is 1.13.7 and uses nixpkgs' Electron 43.8.3 binary. The package wrapper enables Wayland when the session selects it, but neither this feature nor the Electron binary recipe supplies an explicit VA-API option. Chromium's current Linux VA-API guide calls it unsupported/best-effort and documents version-sensitive feature names; do not assume `--enable-features=VaapiVideoDecoder` works. Check `chrome://gpu` and `chrome://media-internals` during actual video playback; the active player's `video_decoder` should identify `GpuVideoDecoder`. No forced feature flag is added because the locked Electron binary's VA-API support and codec build flags are not established by its Nix wrapper. The Legion iHD driver availability alone is insufficient proof.

Outputs include Obsidian, Zotero, LibreOffice Qt, English spelling/hyphenation data, Zathura configuration, document MIME associations, and the Markdown default application. LibreOffice handles all nine configured Office MIME types: legacy and Open XML Word files use `writer.desktop`, spreadsheets use `calc.desktop`, and presentations use `impress.desktop`. PDF files open in Zathura. Use Zotero's built-in reader for PDF annotations; Okular is no longer installed. The locked package source currently declares Zotero 9.0.6 and embeds Firefox ESR 140. The shared `GTK_USE_PORTAL=1` session environment selects Gecko's automatic portal file picker without changing Zotero's existing profile.

Only LibreOffice is installed as the Office suite. Removing the OnlyOffice package and its activation seed does not delete an existing `~/.config/onlyoffice/DesktopEditors.conf` or any documents; that leftover config is outside this feature's writers. Shared Noto/Source Han and office-compatible font availability is supplied by the desktop session font configuration.

When Noctalia is enabled, the feature owns its public `programs.noctalia.settings.theme.templates.user` entries for Zathura and Obsidian; the colors come directly from `user.appearance`, with no Material-derived tokens or community template IDs. Activation seeds a missing Zathura palette file with the same palette as the Noctalia template, preserving any existing file for either session. Zathura opens at `best-fit`, hides the persistent statusbar, and uses 24px horizontal and vertical page gaps. `F4` toggles the native statusbar; `s` remains Zathura's built-in fit-to-width key. `recolor=false` keeps document pages in their authored colors.

`default.nix`, `zathura.nix`, `templates.nix`, `checks.nix`, and `resources/obsidian_theme.py` are owned implementation files; all Nix files here are private except the explicit `checks.nix` hook, which exposes `documents-visual-config` and `documents-mime-config`. The MIME check confirms LibreOffice remains installed and all nine Office MIME types have a matching default handler and Open With association. Zathura uses the appearance monospace font for its UI and shows page percentage when the statusbar is visible. The native `Tab` binding opens the document index in Index mode; Zathura has no persistent directory sidebar. Its native index selection surface has no configurable left stripe, and it has no thin page-progress line, so the selected surface and numeric status readout are the closest equivalents. Obsidian CSS is rendered only into `.obsidian/snippets/noctalia.css` for existing vaults registered in `$XDG_CONFIG_HOME/obsidian/obsidian.json`; missing/offline registry paths are skipped; symlink and malformed paths are rejected. The template declares palette variables only (including semantic RGB and `--vault-*` colors); it emits no component selectors. Minimal and the vault-owned `vaults-ui.css` snippet own the established tabs, navigation, callouts, modals, and dashboard layout. The opt-in `resources/obsidian-quiet-layout.css` is a separate synthetic-vault trial: it lightens tabs and removes raised workspace surfaces while leaving both sidebars usable. Copy it as `.obsidian/snippets/obsidian-quiet-layout.css` in the test vault and enable that named CSS snippet in Obsidian. The Noctalia hook never creates or enables it, and never changes workspace state or hotkeys. Use Obsidian's native Toggle left sidebar / Toggle right sidebar commands and store the collapsed initial state only in the synthetic vault's workspace. The hook only appends the `noctalia` snippet name to each registered vault's `appearance.json`, preserving the chosen theme and all existing snippets. Plugin binaries, portable plugin settings, Home, Bases, and knowledge files are vault-owned and are never deployed by Nix. See [the Obsidian guide](../../../docs/obsidian-handwriting.md) for the established layout and its migration boundary. Removing the feature stops these writers and leaves app configs, vaults, snippet files, enabled snippet entries, Zotero libraries, documents, and application history intact.

LibreOffice keeps its native Qt menu and toolbar structure and inherits the shared Qt palette. Its package wrapper defaults `SAL_USE_VCLPLUGIN` to `qt6`: the Qt-enabled package can otherwise auto-select GTK under Mango. This is application-scoped and an explicit environment override is still honored. The installed 25.8 configuration schema defaults `Office.Common/Appearance/UseOnlyWhiteDocBackground` to `true`, independently of the application theme; this gives a light document canvas without changing saved page formatting or print output. This feature does not own or rewrite `libreoffice/4/user/registrymodifications.xcu`: existing appearance, icon, toolbar, and document choices remain user-owned. In Tools → Options → LibreOffice → Appearance, the native “Use white document background” option remains available if a personal profile differs from that default.

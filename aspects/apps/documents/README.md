# Documents

Installs document applications and chooses handlers for documents. It reads `user.appearance` for the Zathura and Obsidian palette templates.

Outputs include Obsidian, Zotero, LibreOffice Qt, English spelling/hyphenation data, Zathura configuration, document MIME associations, and the Markdown default application. LibreOffice handles all nine configured Office MIME types: legacy and Open XML Word files use `writer.desktop`, spreadsheets use `calc.desktop`, and presentations use `impress.desktop`. PDF files open in Zathura. Use Zotero's built-in reader for PDF annotations; Okular is no longer installed. The locked package source currently declares Zotero 9.0.6 and embeds Firefox ESR 140. The shared `GTK_USE_PORTAL=1` session environment selects Gecko's automatic portal file picker without changing Zotero's existing profile.

Only LibreOffice is installed as the Office suite. Removing the OnlyOffice package and its activation seed does not delete an existing `~/.config/onlyoffice/DesktopEditors.conf` or any documents; that leftover config is outside this feature's writers. Shared Noto/Source Han and office-compatible font availability is supplied by the desktop session font configuration.

When Noctalia is enabled, the feature owns its public `programs.noctalia.settings.theme.templates.user` entries for Zathura and Obsidian; the colors come directly from `user.appearance`, with no Material-derived tokens or community template IDs. Activation seeds a missing Zathura palette file with the same palette as the Noctalia template, preserving any existing file for either session. The Markdown handler is an intentional exception to the generic text editor default.

`default.nix`, `zathura.nix`, `templates.nix`, `checks.nix`, and `resources/obsidian_theme.py` are owned implementation files; all Nix files here are private except the explicit `checks.nix` hook, which exposes `documents-visual-config` and `documents-mime-config`. The MIME check confirms LibreOffice remains installed and all nine Office MIME types have a matching default handler and Open With association. Zathura uses the appearance monospace font for its UI and shows page percentage in the status line. The native `Tab` binding opens the document index in Index mode; Zathura has no persistent directory sidebar. Its native index selection surface has no configurable left stripe, and it has no thin page-progress line, so the selected surface and numeric status readout are the closest equivalents. Obsidian CSS is rendered only into `.obsidian/snippets/noctalia.css` for existing vaults registered in `$XDG_CONFIG_HOME/obsidian/obsidian.json`; missing/offline registry paths are skipped; symlink and malformed paths are rejected. The hook only appends the `noctalia` snippet name to each registered vault's `appearance.json`. Removing the feature stops these writers and leaves app configs, vaults, snippet files, enabled snippet entries, Zotero libraries, documents, and application history intact.

# Documents

Installs document applications and chooses handlers for documents. It reads `user.appearance` for the Zathura and Obsidian palette templates.

Outputs include Obsidian, Zotero, LibreOffice Qt, ONLYOFFICE Desktop Editors, English spelling/hyphenation data, Zathura configuration, document MIME associations, and the Markdown default application. The locked nixpkgs package is ONLYOFFICE Desktop Editors 9.1.0 and declares the launcher ID `onlyoffice-desktopeditors.desktop`. DOC/DOCX, XLS/XLSX, and PPT/PPTX default to ONLYOFFICE; ODT/ODS/ODP default to LibreOffice (`writer.desktop`, `calc.desktop`, `impress.desktop`). Both suites are associated with all nine MIME types so either remains available in Open With. PDF files open in Zathura. Use Zotero's built-in reader for PDF annotations; Okular is no longer installed. The locked package source currently declares Zotero 9.0.6 and embeds Firefox ESR 140. The shared `GTK_USE_PORTAL=1` session environment selects Gecko's automatic portal file picker without changing Zotero's existing profile.

The documents feature wraps ONLYOFFICE's CLI and every command in `onlyoffice-desktopeditors.desktop` with `--xdg-desktop-portal=default`, which the locked 9.1.0 binary identifies as using portals for the current session. The wrapper preserves the package's desktop ID, `pname`, and version. The FHS app still pins its Qt platform to XCB. The application supports a dark interface theme. Activation creates `~/.config/onlyoffice/DesktopEditors.conf` with `UITheme=theme-dark` only when that file does not already exist. The app owns this mutable file after seeding; existing config files and symlinks are left untouched. The nixpkgs FHS package includes Noto CJK Sans; shared Noto/Source Han and office-compatible font availability is supplied by the desktop session font configuration.

When Noctalia is enabled, the feature owns its public `programs.noctalia.settings.theme.templates.user` entries for Zathura and Obsidian; the colors come directly from `user.appearance`, with no Material-derived tokens or community template IDs. Activation seeds a missing Zathura palette file with the same palette as the Noctalia template, preserving any existing file for either session. The Markdown handler is an intentional exception to the generic text editor default.

`default.nix`, `package.nix`, `zathura.nix`, `templates.nix`, `checks.nix`, `resources/obsidian_theme.py`, and `resources/seed-onlyoffice-config.py` are owned implementation files; all Nix files here are private except the explicit `checks.nix` hook, which exposes `documents-visual-config`, `documents-mime-config`, `documents-onlyoffice-portal-wrapper`, and `documents-onlyoffice-config-seed`. The wrapper check verifies the CLI wrapper and every desktop launcher command carries the portal flag without launching the GUI. The seed check verifies initial dark config creation and preservation of existing regular files and symlinks. Zathura uses the appearance monospace font for its UI and shows page percentage in the status line. The native `Tab` binding opens the document index in Index mode; Zathura has no persistent directory sidebar. Its native index selection surface has no configurable left stripe, and it has no thin page-progress line, so the selected surface and numeric status readout are the closest equivalents. Obsidian CSS is rendered only into `.obsidian/snippets/noctalia.css` for existing vaults registered in `$XDG_CONFIG_HOME/obsidian/obsidian.json`; missing/offline registry paths are skipped; symlink and malformed paths are rejected. The hook only appends the `noctalia` snippet name to each registered vault's `appearance.json`. Removing the feature stops these writers and leaves app configs, vaults, snippet files, enabled snippet entries, Zotero libraries, documents, and application history intact.

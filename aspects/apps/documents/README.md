# Documents

Installs document applications and chooses handlers for documents. It reads `user.appearance` for the Zathura and Obsidian palette templates.

Outputs include Obsidian, Zotero, Okular, LibreOffice, English spelling/hyphenation data, Zathura configuration, PDF MIME association, and the Markdown default application. When Noctalia is enabled, the feature owns its public `programs.noctalia.settings.theme.templates.user` entries for Zathura and Obsidian; the colors come directly from `user.appearance`, with no Material-derived tokens or community template IDs. Activation seeds a missing Zathura palette file with the same palette as the Noctalia template, preserving any existing file for either session. The Markdown handler is an intentional exception to the generic GUI text editor default.

`default.nix`, `zathura.nix`, `templates.nix`, `checks.nix`, and `resources/obsidian_theme.py` are owned implementation files; all Nix files here are private except the explicit `checks.nix` hook, which exposes `documents-visual-config` to validate generated Zathura/Obsidian themes and the Obsidian fixture tests. Zathura uses the appearance monospace font for its UI and shows page percentage in the status line. The native `Tab` binding opens the document index in Index mode; Zathura has no persistent directory sidebar. Its native index selection surface has no configurable left stripe, and it has no thin page-progress line, so the selected surface and numeric status readout are the closest equivalents. Obsidian CSS is rendered only into `.obsidian/snippets/noctalia.css` for existing vaults registered in `$XDG_CONFIG_HOME/obsidian/obsidian.json`; missing/offline registry paths are skipped; symlink and malformed paths are rejected. The hook only appends the `noctalia` snippet name to each registered vault's `appearance.json`. Removing the feature stops these writers and leaves vaults, snippet files, enabled snippet entries, Zotero libraries, documents, and application history intact.

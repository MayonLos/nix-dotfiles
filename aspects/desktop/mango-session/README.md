# Mango session

Provides the Mango Wayland desktop and its Noctalia shell integration. Inputs are `user.appearance`, host display facts, selected `noctaliaIntegrations`, and the public `nixDotfiles.graphicalSessionTargets` option from session support.

Outputs include Mango/Noctalia configuration, clipboard bridges, screenshot and OCR tools, per-session environment, and host-side Mango/portal modules routed through `interactive-session-host`. The `noctaliaIntegrations` quirk is declared here and validated by `contract.nix` before it is consumed to render selected application integrations. The feature owns its session target and Noctalia service lifecycle; it does not select the login greeter.

Noctalia settings are rendered by `noctalia.nix`; its package is built from the locked `pkgs.local.noctalia` derivation with `noctalia/astra-selection.patch`. The patch keeps launcher selection and active Home shortcuts on a faint palette hover surface, uses blue foregrounds, adds minimal workspace underlines/occupancy dots, and turns the Home layout into a vertical stack with a full-width three-column shortcut grid. The same patch inserts native volume/brightness sliders between the grid and media card; Home uses no sidebar and its configured width is not reduced by the native sidebar multiplier. Brightness commits when a drag/key step completes; its value reads the first controllable display and changes all controllable displays. The bar is 30 logical pixels high, uses thin separators instead of filled group capsules, and keeps infrequent tools in an accordion anchored by the already-visible Quill entry. Group background opacity is explicitly zero; disabling per-widget capsules alone would retain the native group fills. The two clock widgets render the Chinese date and Maple Mono time separately. The pinned community system-monitor supplies the default CPU summary; native GPU, VRAM, and RAM widgets expand in the monitor accordion. The pinned nix-status and nix-search plugins are enabled, with `nix-search-tv` and `fzf` declared as runtime packages. Targeted read-only inspection confirmed the old managed file omitted `shell.app_icon_colorize` while the runtime sidecar set it to true, causing grayscale/tint. The new managed false value is covered by the existing public-key reconciliation; no runtime state was changed during implementation. Launcher icons preserve their source colors; launcher, control center, and notification widths are 560, 380, and 320 logical pixels.

Legion conservation mode is exposed through a local Noctalia status plugin, which polls the host command asynchronously and displays green `养护` only while active. The battery widget's left click invokes `legion-conservation toggle`; the command itself is supplied by the separately owned `hardware/legion-laptop` feature. The community plugin source keeps its original `community` identity and all untouched plugin directories as store symlinks. A build-time overlay copies only `mango_layouts` and `nix-status`: it adds the plugin's `zh-CN` translations and reads the active generation number by matching `/run/current-system` to `/nix/var/nix/profiles/system-N-link`. The nix-status details panel and service remain intact. The pure generation-number parser test is `resources/noctalia-community/nix-status/tests/generation_number_test.luau`; run it from the patched plugin directory with `luau tests/generation_number_test.luau` when Luau is available. The feature also supplies the pinned Neovim terminal desktop entry and `notify-send` (`libnotify`) for notification review. The managed Noctalia user service sets `LC_TIME=zh_CN.UTF-8` for Chinese date labels. `runtime-check.nix` runs the locked binary's `config validate` and checks serialized UI settings; this is build-time validation, not a live desktop session test.

`default.nix` and `contract.nix` are public. `mango.nix`, `noctalia.nix`, `noctalia/`, `clipboard.nix`, `screenshot.nix`, `tesseract-ocr.nix`, and `host/` are private implementation. `checks.nix` is a public test hook with signature `{ pkgs, lib, system, nixos, home, appearance }` (as needed). Other Nix files are private.

Removing the feature withdraws Mango and Noctalia configuration, session services, and screenshot/clipboard declarations when a new generation is activated. It leaves user documents, Noctalia history/settings outside declared paths, saved sessions, and other application state untouched; it does not stop or switch the running session by itself.

HM owns `Pictures/Wallpapers/managed` as a store link. The `wallpaperLocalDirectory` activation only creates a missing `Pictures/Wallpapers/local/`, preserves existing directories and directory symlinks, and refuses other existing objects without replacement. Noctalia scans the parent recursively, following directory symlinks with canonical-path deduplication. User local images remain outside Git/store and survive feature removal. Native automation also chooses a random image at shell startup; the declared default and greeter use Quiet Bay, while the lockscreen follows the current desktop wallpaper.

# Media, browser, and messaging apps

`modules/home/programs/apps/mpv.nix` configures Vulkan playback and Anime4K shaders. The active shader list is repeated in the `Ctrl+1` binding; update both when changing that chain. Check GPU backend and codec support against the host's current graphics packages.

`zathura.nix` includes the mutable `noctaliarc` generated by Noctalia; keep theme colors out of later Home Manager options when they would override that include. Zen was removed on 2026-09-29. Firefox replaced Chrome on 2026-10-01; `firefox.nix` seeds UI preferences and a static fallback `userChrome.css` into the current default profile, while Noctalia's Firefox user template updates its managed CSS block when the palette changes. Neither owns the profile database or other preferences. Firefox reads those changes on restart.

`im.nix` wraps QQ to add PipeWire library lookup and pins its launcher to Wayland; WeChat UOS pins Qt to XWayland. These declarations describe launch requests, not proof of the protocol used by every running process. Check the current package version, wrapper, and live protocol before changing flags; fcitx5 sizing is covered in the desktop-mango input/clipboard reference.

For QQ copy/paste or IME symptoms, read
[input and clipboard](../../desktop-mango/references/input-clipboard.md).
Window protocol alone does not determine selection protocol.

Do not infer that QQ or another Electron client's screen-share picker uses the portal merely because the binary contains portal strings. Verify that the active picker issues a portal request and inspect the portal logs. A prior binary inspection found an X11 enumeration path in QQ, but that dated observation is not a guarantee for a newer build. The 2026-10-01 Wayland screenshare launcher and its QQ 3.2.34 pin were removed. Keep screen-share diagnosis separate from the PipeWire library wrapper, which only addresses library loading.

The OBS application remains installed in `obs-studio.nix`. A separate system
v4l2loopback/virtual-camera setup was removed at the user's request; its absence
is not a missing module to restore during cleanup. Consider a browser's portal
sharing path before proposing system-level camera emulation.

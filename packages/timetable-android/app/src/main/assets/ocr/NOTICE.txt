Offline OCR assets bundled with Timetable Android

The detector and recognizer are RapidOCR ONNX conversions of PaddleOCR PP-OCRv4
mobile Chinese models. Upstream model configuration and provenance:
https://github.com/RapidAI/RapidOCR/blob/main/python/rapidocr/default_models.yaml
https://github.com/RapidAI/RapidOCR/blob/main/LICENSE
https://github.com/PaddlePaddle/PaddleOCR

The recognizer's `character` list was read from the ch_PP-OCRv4_rec_infer.onnx
custom metadata map, using the same metadata key and ordering used by RapidOCR
1.4.4. It is reproduced in keys.txt. The blank CTC label is index 0 and the
space label follows the final metadata character, matching RapidOCR's decoder.

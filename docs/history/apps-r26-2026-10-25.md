## 实现

- 移除 Okular 及所有 MIME 关联。PDF 仍默认 Zathura，批注改用 Zotero 内置阅读器。用户称“Zotero 7”，当前锁定 nixpkgs 实际为 **9.0.6 / Gecko ESR 140**，没有为匹配旧名称降级。
- File Roller **44.7** 替代 Xarchiver，锁定二进制链接 GTK4/libadwaita。Thunar Archive Plugin **0.6.0** 的 TAP 将 File Roller 固定为绝对路径。File Roller 闭包携带 Nautilus；目录 MIME 和唯一用户 FileManager1 服务显式选 Thunar，不依赖候选顺序。
- Thunar **4.20.9** 的 host、HM、D-Bus、systemd 入口使用同一包装包。锁定 NixOS 模块无 `programs.thunar.package`，按原模块明确注册系统包、D-Bus、systemd 和 Xfconf。包装输出移除原生 wallpaper 插件链接：该插件仅支持 XFCE/GNOME，在 Mango/dwm 会无效；不修改上游 store 文件。
- Qt6ct **0.11** 使用 `standard_dialogs=xdgdesktopportal`。在现有安全普通配置上维护该键，保留用户其他设置和 CRLF；文件或父路径软链不写穿。KDE 配色与 Tela-circle-dark 由 HM 独占生成 `kdeglobals`/色板，Qt 保留 Fusion 和共享 One Dark roles/QSS。额外审计补齐 qt6ct 的 `QT_PLUGIN_PATH` 到 shell/systemd/Mango：只安装 qt6ct 或只设置主题名称不足以让其他 Qt 应用发现 QPA 插件。
- Firefox、Thunderbird 的包级偏好固定 `widget.use-xdg-desktop-portal.file-picker=1`；Zotero 的 Gecko 自动分支使用会话 `GTK_USE_PORTAL=1`，不接管既有 profile。QQ 的 Electron 使用支持的 `--xdg-portal-required-version=3`，不叠加会覆盖原特性的 `--enable-features`。锁定 Electron 43.7.11 的 Obsidian/Vesktop 使用默认 portal 支持。
- GTK3/4 继续由 Noctalia 主题模板唯一写入 CSS，GTK4 不强制 GTK3 theme。GTK2 改用真实存在的 `gnome-themes-extra` Adwaita-dark 引擎，HM 提供 One Dark widget roles 和 GTK2 ABI 根目录 `GTK_PATH`；私有 GTK2 demo 确认引擎加载、GTK3 Thunar 回归另列，避免继承不存在的 adw-gtk3 GTK2 资源后回退浅色。
- OnlyOffice **9.1.0** 与 LibreOffice Qt 并存。DOC/DOCX、XLS/XLSX、PPT/PPTX 默认 OnlyOffice；ODT/ODS/ODP 默认 LibreOffice；九种 MIME 均关联两者。CLI 与 desktop actions 走同一个 portal wrapper，传递锁定二进制支持的 `--xdg-desktop-portal=default`。仅缺失时 seed `UITheme=theme-dark`，既有配置归应用所有。隔离启动已确认扁平 seed 被读取，并由应用重写为 `[General]` 分组。
- 中文字体复用 Noto CJK Sans/Serif，增加思源 Sans/Serif；Carlito、Caladea、Liberation 提供 Calibri/Cambria/Arial/Times New Roman/Courier New 替代；SimSun/微软雅黑别名到 Noto CJK。隔离 fontconfig 的九项 `fc-match` 检查通过。这不代表任意复杂 Office 文档排版完全一致。
- 只保留 swayimg 作为图片查看器；GIMP 是编辑器。锁定 **4.7 的 INI**，One Dark 底栏显示文件名、尺寸、缩放与序号；左右/h/l 切换，r/Shift+r 旋转，f 适应，1 原始大小，Delete 确认后 trash-cli，Ctrl+c 复制首帧 PNG，Ctrl+g 打开 GIMP。禁用原生永久删除快捷键。局部补丁增加安全的 `%q` 路径展开，C 检查执行包含引号、命令替换、反引号、换行的文件名，确认保持字面值。
- 光标共享来源改为 `phinger-cursors-light`，32；HM pointerCursor、GTK、Xresources、XCURSOR 环境、Mango/Xorg/dwm 和 greeter 保持一致，不新增 Kitty writer。1.5 缩放下比较 24/32 后采用 32（48 物理像素名义尺寸）；截图 `thunar/cursor-{24,32}-scale-1.5.png`。上游推荐 32，见 [phinger-cursors](https://github.com/phisch/phinger-cursors)。

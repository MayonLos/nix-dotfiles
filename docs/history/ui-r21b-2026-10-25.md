## 实现与归属

- `session-support/gtk.nix` 保留 adw-gtk3-dark 与原有 Bibata 声明，图标包改为 Tela-circle（默认蓝色变体的实际名称为 Tela-circle-dark）。共享 appearance 的图标名只改一处；Xorg Dunst 从公开 GTK option 复用同一 name/package，避免名称已变而仍安装旧包。没有改窗口规则、光标环境、Mango/顶栏或 Neovim。
- GTK3 正式 Noctalia 模板：deep 侧栏与工具栏、selection/左蓝条、圆角路径容器与当前段蓝下划、细分隔、小号等宽表头/状态、sans 文件名。Thunar 4.20 真实侧栏 class 是 `.shortcuts-pane`。toolbar image 清零 margin/padding 并设16px下限，修复窄按钮 GtkImage 的 negative content width。
- Thunar 的 `follow-state` renderer 会以 SELECTED/ACTIVE 的背景色进行 Cairo MULTIPLY，深色选中底把图标乘黑。针对实际 Exo `widget.view` 节点，将计算背景设为透明，改用 selection 颜色的纯色渐变层画标签底；保留原色图标与选中标签。两种焦点状态都覆盖，不改 Thunar 包。
- GtkTreeView 不提供逐 cell CSS node，细节/文件选择器整行填 selection，避免左线在每列重复。GTK3 无文本大写转换，表头保留原生文本；侧栏宽度、zoom、窗口尺寸仍归用户。
- GTK4/libadwaita 同时配置 legacy symbolic colors 与当前 CSS custom properties，保留原生几何；suggested action 使用 selection 底、亮字和蓝下划。只对实测应用提供截图证据，不承诺覆盖私有控件。
- Qt 保留 Fusion 和22角色 palette，HM 独占 `qt6ct/qss/one-dark.qss`，补充圆角输入/按钮、tab 下划、焦点、细分隔。全局字体继续由 qt6ct Fonts 配置持有，QSS 仅在 header/status 局部使用 mono；不以 QWidget 字体规则覆盖用户 GUI 字体。
- qt6ct.conf 仍为 GUI 可变文件：缺失 seed，完整旧/当前未引号仓库默认字体规范为 QSettings quoted QString，旧 Papirus-Dark 默认图标迁到新值，缺失 managed QSS 引用追加到既有 QStringList。其他 icon/style/font、未知 section、用户 stylesheet 顺序保留；未知 typed value、十六进制及 @@ 转义保守原样保留，不将其重写为错误路径。重建会补回 managed QSS 引用。seed/迁移拒绝目标及父路径 symlink，CRLF 与幂等保留。截图另发现原十字段 QFont 的 weight 400 实际解析为900；seed 与被识别的仓库默认改为该格式的正常值50（Qt 6解析为400），并以真实 QFont.fromString 验证字重和11pt，而非只比较字符串。没有启动用户设置 GUI 或 reload 应用。
- Noctalia 继续独占 GTK CSS/import hooks 与 qt6ct runtime palette，HM 没有新增 GTK CSS writer。Xorg-only 新账号仍遵循原 GTK writer 边界：安装基础主题，完整 GTK CSS 在选中的 Noctalia 生命周期生成；Qt 有独立缺失 palette seed。移除 feature 不删除用户应用数据和 GUI 配置。

## 精确原色修正

真实模板检查发现，锁定 Noctalia 5.3 的 `src/theme/template_engine.cpp::applyCustomColors()` 即使 `blend=false`，仍把普通 custom color 映射为 Material tone 80/40；`*_value` 才是传入的原色。旧模板的 blue 实测被渲染为 `#9acbfa`，bg 被渲染为 `#a2c9fd`，与固定 One Dark 不符。本轮 GTK3/4、Qt palette 改读 `colors.onedark_*_value.default.hex`。Firefox 的同组 runtime 引用及 fallback 置换表同步更正，使 GTK/Qt/Firefox 保持同一原色，没有改 browser 布局或用户 profile 归属。

新增 `gtk-qt-theme` 功能检查，使用真实 Noctalia 离线引擎、生产 asset bundle 和 custom palette 渲染三个模板，不运行 builtin hooks；GTK3/4 的原生 CSS provider 解析输出，真实 Qt QSettings 读回 seed 与迁移配置。Firefox fixture 也实际渲染 runtime 模板，并与 fallback 逐字比较。测试能发现色阶误用及 INI 引号错误，而非仅扫描源码字符串。

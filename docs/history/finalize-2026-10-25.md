## 对比度

`palette-contrast` 从 palette 读取源色，执行 sRGB 线性化和 WCAG 相对亮度公式，共 24 项门槛。
其报告为 check 的 store 输出文件，非硬编码结果。

| 组合 | 比值 / 范围 | 门槛 |
|---|---:|---:|
| brightFg / bg、deep、surface、selection | 11.41 / 12.33 / 10.03 / 8.41 | 7 |
| fg / bg、deep、surface、selection | 7.49 / 8.10 / 6.59 / 5.53 | 4.5 |
| blue / selection | 4.99 | 4.5 |
| muted / bg、deep | 4.58 / 4.95 | 4.5 |
| cyan、blue、green、orange、fg / deep | 7.29 / 7.31 / 8.56 / 7.01 / 8.10 | 7 |
| brightFg / diff 8% 与 12% 合成底 | 9.79–11.17 | 7 |
| bg .98 覆盖纯白后的 brightFg / fg | 10.79 / 7.09 | 7 / 4.5 |

muted 的提亮仅改变消费该 token 的辅助文字和装饰；在 surface/selection 上仍低于 4.5，
必要说明使用 fg，正文使用 brightFg，不把 ghost text 色用于所有必要说明。

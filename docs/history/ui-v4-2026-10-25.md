Mango、Noctalia、greeter、herdr 的局部补丁均留在所属 feature 内。升级输入时必须检查源码结构、patch 应用、关键字符串与生成配置，再构建 package/checks 和 toplevel；禁止忽略 patch 错误或用旧字符串检查冒充新布局仍存在。uosc 的有限 Python 源码变换同样对旧锚点数量断言。应用程序能力限制不等于构建失败：TUI 线条是字符单元，Zathura 无文件目录侧栏/独立进度线，uosc 无选中发光，分别用目录索引/页百分比和平面细蓝线。
